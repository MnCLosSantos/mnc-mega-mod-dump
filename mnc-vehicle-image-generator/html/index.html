How to Setup

  1. Only have 250 models in config per use of capture
  2. Use the /vehlist command
  3. go into the script folder and copy the contents of vehlist1.lua and replace the VehicleSpawnCodes in the config.lua
  4. Enter your Discord webhook URL
  5. Setup camera ect using ingame ui
  6. Copy the outputs for Config.CameraSettings/Config.ScreenshotSettings into Config.CameraSettings/Config.ScreenshotSettings
  7. Now follow the next guide

How to Use

  1. Select vehicles (use "Select 250" for safety)
  2. Set chunk size (25 MAX) unless u wanna crash the server
  3. DO NOT DO MORE THAN 250 TOTAL AT A TIME
  4. Click Start Capture
  5. Wait To Complete
  6. Refer to the guide of the type u want png/discord
  7. Remove images from vehicle-images folder
  8. Remove the contents of vehicle-images.json
  9. Remove the Config.VehicleSpawnCodes from vehlist1.lua and replace with vehlist2.lua and repeat

How to Use

  1. Once capture is complete copy the images from "vehicle-images" folder
  2. Remove images from vehicle-images folder
  3. Remove the contents of vehicle-images.json
