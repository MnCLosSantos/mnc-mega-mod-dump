1. API Key

Get a key at finevoice.ai/usercenter → API Tokens. Saved only in this browser's local storage — never sent anywhere except directly to FineVoice's API.
Heads up: FineVoice's own docs warn against using API keys in client-side code, since anyone with access to this page (or its source) can read the key. That's an inherent tradeoff of a plain HTML tool with no backend — fine for your own local use, just don't publish this file anywhere public with your key saved in it.

Troubleshooting

    

      Test/preview audio generates but you hear nothing: browsers block auto-playing audio that isn't started
      by a direct, immediate click — since generating a preview involves a short wait for the API, the browser often
      refuses to auto-play the result. The player will still appear above the "Test voice" button — press its own
      ▶ play button once the status line says "ready". This tool no longer assumes autoplay will work.


      Requests fail immediately with a network/CORS error: FineVoice's API may not allow direct browser
      (cross-origin) calls — their docs are written assuming a server-side client. If that happens here, the fix is a
      tiny local proxy: run a one-line script that forwards requests from this page to apis.finevoice.ai
      and adds your key server-side, then point this tool at your proxy's URL instead. Ask me and I'll build that
      companion script if you hit this.


      401 error: check the API key was pasted correctly and saved.

      422 error: the voice name/ID is probably wrong — use 🎭 Browse voices to confirm it.

      "Unexpected task status" error: FineVoice's task-status field doesn't always match their own docs
      (it can come back as a number like 200, or a string like "completed", "success", or something else entirely).
      This tool now treats "completed", "success", "succeeded", "done" and "finished" all as success — if you still
      see this error, open the raw response shown in the error message and tell me the exact status value so the
      check can be widened further.

      A file times out: very long lines can take longer than this tool's ~3 minute polling window; try shorter lines.
